# 修炼闭环实现进度

更新时间：2026-07-30

## 已完成

- 首页“修炼”入口可进入修炼场景，并立即给出进入提示。
- 修炼单次时长为 5 分钟，开始时扣除 10 点精力；结束后自动结算并回到洞府待机。
- 修炼状态、剩余时间、精力及修为进度写入 NVS。重启后，若修炼尚未结束，会按可信时间恢复修炼状态。
- 修炼过程按境界计算确定性的顿悟/心魔结果：前期顿悟概率较高、境界提升后降低；心魔概率随境界略升。无论事件结果，单次修炼都会增长修为。
- 顿悟在修炼中段出现，特效持续到本次修炼结束。
- 接入 PCF85063 RTC：联网校时后写入 RTC，后续离线开机可恢复时间；首页日期/时间每 10 秒轮播。
- 修炼背景、男女角色帧和顿悟特效改为 TF 卡直接读取的原始 LVGL 格式，避免在 LVGL 任务中解码大 PNG 导致看门狗复位。
- 修炼场景进入时暂停待机人物刷新；退出时释放修炼资源、恢复洞府背景与待机人物，避免场景资源叠加。
- 首页境界层数、日期时间、精力和对话气泡位置已按当前界面调整；境界进度条按当前层的 100 点修为循环显示。
- 待机状态下精力每 5 分钟恢复 1 点；只有数值变化时才写入 NVS 并刷新首页。
- 底部当前只开放“修炼”入口；历练、札记和商城均明确提示正在开发中，不会触发未完成逻辑。
- 游戏状态变更采用候选状态、NVS 成功提交后再替换运行状态的流程，避免保存失败造成精力或奖励与存档不一致。
- 主板文件已拆分至 2000 行以内，角色分层动画和对话控制器迁至 `immortal_pet/`。

## 资源同步

运行以下脚本生成修炼资源，再将 `docs/images/sdcard/immortal_pet` 下对应目录同步到 TF 卡：

```powershell
python firmware/device/scripts/immortal_pet/convert_cultivation_assets.py
```

生成的 `.rgb565` 与 `.argb8888` 文件位于：

`docs/images/sdcard/immortal_pet/scenes/cultivation/`

该资源目录不提交到 Git，TF 卡资源需单独同步。待机/行走的分层人物帧目前仍使用 PNG，后续应采用同样的原始格式转换方案。
