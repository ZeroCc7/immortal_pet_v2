# 修炼闭环实现进度

更新时间：2026-08-02。

## 已实现

- 首页“修炼”入口进入独立修炼场景。
- 单次修炼持续 `5` 分钟，开始消耗 `10` 精力。
- 基础收益为 `10` 修为；顿悟为 `16`，心魔为 `7`。
- 修炼结束自动结算并返回洞府，不存在手动领取步骤。
- 活动、剩余时间、精力、修为和确定性事件写入 NVS。
- 联网校时后写入 PCF85063 RTC；离线冷启动可恢复可信时间。
- 修炼场景使用 TF 卡 RGB565/ARGB8888 资源，进入时暂停首页绘制，退出时释放场景资源。
- 所有状态变化使用候选状态提交；保存失败不会扣除精力或发放奖励。
