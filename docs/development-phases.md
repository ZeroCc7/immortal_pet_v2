# 下一阶段开发路线

## 总体约束

- TF 卡是游戏内容的必需介质：首页、历练、兵器铺等重型场景互斥；同一时间只保留当前场景资源。
- 未挂载 TF 卡或核心内容加载失败时，设备显示纯文字安全页。
- 人物性别首次建档后固定；外观和武器层必须与已选性别兼容。
- V0 的权威进度状态为修为、灵石、精力和进行中的活动；不增加独立经验值、等级、心情、羁绊或材料。
- 游戏数值和活动结算由本地确定性规则计算；语音、LLM、动画和场景只读取状态并表达结果。
- 每次状态变化均先生成候选状态，NVS 成功提交后才替换内存状态和刷新 UI。

## 游戏时钟与 RTC

进度（2026-07-30）：PCF85063 RTC 已接入。联网校时后写 RTC；离线冷启动优先从有效 RTC 恢复系统时间。游戏时钟固定使用中国标准时间（UTC+8），首页时钟和日夜背景共用该时间源。

- NVS 保存最近可信时间；检测到明显回拨时，游戏时间不得倒退结算活动。
- 修炼和历练活动的时长均以可信墙上时间恢复，以支持重启后的活动续接；精力恢复只影响修炼。
- RTC 数据无效且网络尚未校时时，首页仍可显示，但不得把无效时间用于活动结算。

## 当前确认的境界展示规则

- 首页境界完全由累计修为推导，不单独写入存档。
- 修为为 `0` 时不显示境界名、层级图或修为进度条；从修为 `1` 开始为炼气一层。
- 每累计 `100` 修为提升一层；每个境界有 `15` 层，依次为炼气、筑基、金丹、元婴、化神、合体、大乘、渡劫。
- 境界名与层级图从 TF 卡 `/sdcard/immortal_pet/home` 按需读取。

## 第一阶段：角色建档与洞府首页（已完成）

- 无档案时显示男修、女修二选一，并将性别写入 NVS。
- 首页洞府背景、分层人物、日夜背景和菜单资源从 TF 卡按需加载。
- 性别、待机人物和洞府首页已完成真机验证。

## 第二阶段：精力制修炼闭环（已完成）

### 权威玩法规则

- 角色精力上限为 `100`；待机时每 `5` 分钟恢复 `1` 点。
- 单次修炼持续 `5` 分钟，开始时消耗 `10` 点精力。
- 修炼完成后自动结算并回到洞府待机，不提供额外领取步骤。
- 修炼获得修为；顿悟和心魔为由本地规则计算的展示事件，不改变“本次修炼增长修为”的结论。
- 权威存档包含修为、灵石、精力、活动类型、活动起止时间、精力恢复锚点和修炼事件；境界、层级和进度条均为派生状态。
- 重启后恢复未结束活动；已到期活动只允许自动结算一次。保存失败时不得扣除精力、开始活动或发放结算奖励。

### 已完成内容

- 修炼场景、5 分钟活动、自动结算、NVS 恢复和精力显示已实现并完成实机验证。
- PCF85063 RTC 已用于联网校时写入和离线冷启动恢复。
- 修炼场景的背景、男女角色帧和顿悟特效使用 TF 卡原始 LVGL 格式；离场时释放资源并恢复洞府待机。

## 第三阶段：手动历练与自动战斗（下一阶段）

详细关卡、奖励和自动战斗基线见 [历练关卡设计](journey-stage-design.md)。

范围：

- 开放首页“历练”入口，提供关卡选择和二次确认；复用活动恢复、自动结算和原子存档机制，且不消耗精力或灵石。
- 关卡按修为门槛逐级开放，难度、时长、怪物数、回合数和单怪灵石奖励一并递增；历练不消耗精力或灵石，击败一只怪即获得该怪对应的灵石。
- 增加后山场景与短时自动回合战斗；首版只加载当前人物、本场敌人和必要动作。兵器铺完成后再接入武器攻击加成。
- 历练结束自动结算灵石；失败只提前返程，不死亡、不扣除已有资源。
- 每次进入、退出后山均按当前场景生命周期加载和释放背景、敌人及动作资源。

验收：

- 历练活动重启后可恢复，完成后只结算一次。
- 活动进行中或时间无效时，不得开始历练或修改存档。
- 多次进入、退出历练后，PSRAM 水位不持续下降。
- 历练期间语音和音频链路不出现阻塞或看门狗复位。

## 第四阶段：兵器铺与装备（后续）

- 建立首页与兵器铺的互斥资源生命周期；首页第四入口改为兵器。
- 支持未解锁、可购买、已拥有和装备中四种武器状态。
- 购买扣除灵石，成功后写入拥有列表并自动装备；已购买武器可免费切换。
- 商店列表只加载缩略图，预览只加载当前选中武器；装备后首页武器层立即更新。
- 武器价格、解锁条件和攻击数值在本阶段单独定稿；不得沿用已废弃的等级或三时段门槛。

## 第五阶段：陪伴表达与稳定性（后续）

- 向语音服务提供只读的性别、修为、灵石、精力、活动和武器快照。
- 增加修炼、历练、购买和返程节点的角色台词。
- 完成断网、TF 卡异常、低电量、长期运行及场景反复切换测试。

## 已废弃的玩法方案

以下方案不再用于实现：早、中、晚三时段行动、休息加成、同日收益递减、独立经验/等级、每境界十层、手动领取奖励，以及以每日行动代替精力和活动时长的规则。旧设计和计划仅作历史记录。
