# 首页实现进度

最后更新：2026-07-29

## 已完成

- 首页使用全屏修仙场景背景；洞府背景、人物与动作均从 TF 卡加载，
  不再纳入默认资源包。TF 卡未挂载或核心素材加载失败时，设备显示纯文字安全页。
- 左上角已保留境界、等级与经验进度的位置；中间不再显示旧版圆形“宠物表情”。
- 未配置小智时，不再展示默认聊天气泡、配网提示或无意义的系统文字；仅在玩家主动交互或后续 AI 返回内容时显示气泡。
- 底部入口改为四张大尺寸竖版玉绿金边卡片，采用“图标在上、文字在下”的布局，参考已确认的设计稿。
- 已生成并压缩四个首页图标：修炼、游历、收获、札记。图标与背景位于 `firmware/device/main/assets/immortal_pet/home/`，并已接入固件资源打包。
- 当前入口与旧版功能绑定保持兼容：修炼、游历、收获、札记；这样可先完成首页视觉验收，不改动既有动作逻辑。
- 首页已完成真机烧录验证，背景、角色待机帧动画和底部入口的实际显示效果符合当前设计方向。
- 待机角色已从 GIF 切换为 LVGL 帧动画：使用 `docs/images/raw/nv1/stand` 的第 024–035 帧，按原始锚点合成为统一的 299×226 透明 PNG 画布，以约 8 FPS 循环播放；其他交互动作暂保留 GIF。
- 已接入 TF 卡 SPI 挂载：GPIO1/MOSI、GPIO2/SCK、GPIO3/MISO、GPIO41/CS。挂载成功后使用 `/sdcard`，顶部显示 TF 状态徽标；TF 卡不可用不会阻断设备启动。
- 已纳入原始男女角色素材库：男女各有 8 个方向的待机和行走帧，为后续角色选择、方向移动和历练场景做准备。
- 已实现首次启动的男女选择与 NVS 存档；存档仅保存性别，初始角色不装备武器。
- 已实现基于 TF 卡 `layered_idle/catalog.json` 的男女分层角色加载、待机和自主行走；人物本体与武器图层保留为独立对象，当前按“初始无武器”规则仅加载人物本体。
- 首页菜单、境界标题和徽章均从 TF 卡加载。左上区域采用无底板的紧凑布局，隐藏修为时速与 `0 / 100` 文本，仅保留进度条。
- 已接入一对 480×480 洞府日夜背景：运行包位于
  `immortal_pet/scenes/dongfu/background_day.png` 与 `background_night.png`；
  使用已校准的游戏时钟，18:00–07:00 自动切换夜景，其余时间使用日景。未校准或检测到时间回拨时保持日景。

## 当前限制

- 完整男女八方向资源约 6 MB；当前内置 assets 分区为 8 MB，不能与既有约 4.6 MB 默认资源包一次性打包。完整资源应从 TF 卡按需读取，内置资源仅保留默认角色与启动兜底素材。
- TF 卡角色帧已可通过 FATFS 和资源清单按需读取；当前加载器在切换前完整加载新角色，避免替换失败后丢失当前形象。
- 性别选择已接入首次存档和男女角色切换；重置时擦除 NVS 分区会同时清除 Wi-Fi 配网信息。
- 入口尚未切换为最终的“早/中/晚：修炼、历练、休息”三时段规则；收获与札记仍复用当前原型的交互。
- 装备、商店、境界突破和角色阶段外观尚未接入首页；性别本地存档已完成。

- 校准后的 18:00 与 07:00 前后，首页在一小时内分别切换到夜景与日景；时间未校准或回拨时保持日景。
