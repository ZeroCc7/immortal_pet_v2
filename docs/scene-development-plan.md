# 横版场景开发计划

## 资源与内存

- 屏幕固定为 480x480；场景背景可使用更宽的源图，通过镜头裁切显示。
- 场景资源放 SD 卡。进入场景时加载当前背景、角色当前动作帧和必要前景；离开时释放旧资源。
- 不缓存多个完整场景，不在每帧从 SD 卡读取或解码大图。

## 通用状态

- `scene_id`：当前场景，例如 `dongfu`、`back_mountain`、`cultivation_room`。
- `player_world_x`：角色世界横坐标。
- `facing`：朝向；女初始素材暂用待机 `05/06`、左行 `00`、右行 `04`。
- `camera_x`：背景镜头坐标。角色靠近屏幕中部后，优先移动镜头而非继续移动屏幕坐标。

## 第一阶段：洞府

- SD 卡运行背景：`immortal_pet/scenes/dongfu/background_day.png` 与
  `background_night.png`，均为 480x480。设备按中国标准时间在 18:00–07:00 使用夜景，
  其余时间使用日景；时间未校准或检测到回拨时保持日景。
- 960x480 原始横版图保留为 `background_panorama_960x480.png`，等分块镜头渲染器完成后再启用。
- 女初始角色随机转向、随机选择目标横坐标、以左右行走帧抵达后停下。
- 首页功能按钮只提示“该功能暂未开发”。

## 后续阶段

1. 把当前屏幕坐标移动升级为世界坐标和镜头跟随。
2. 增加场景清单和切换过渡，按 `scene_id` 从 SD 加载背景。
3. 增加场景边界、可交互地点和活动入口。
4. 将场景 ID、世界坐标、朝向和解锁状态写入 NVS。
