# 兵器铺玩法与资源

更新时间：2026-08-02。

## 当前玩法

- 商店共 `32` 件装备：`22` 把武器和 `10` 套法衣。
- 武器包含金系枪 `01134`–`01144` 和火系扇 `01101`–`01111`。
- 武器外观档位为 70、80、90、100、110、120、130、140、150、160、170。
- 法衣档位为 70、80、90、110、120、130、140、150、160、170。
- 每件物品有修为门槛、灵石价格、外观档位和 `combat_bonus`。
- 未拥有物品购买成功后扣除灵石、写入拥有位图并自动装备。
- 已拥有物品可以免费切换；武器和套装分别保存。
- 保存使用候选状态提交，失败时不扣灵石、不改变拥有或装备状态。

当前 `combat_bonus` 已保存并显示，但尚未接入历练伤害公式。

## 商店界面

- 左右图片按钮切换装备，点击区域为 96×96，靠屏幕两侧。
- 返回按钮位于左下角。
- 主按钮位于底部，显示购买或装备操作。
- 中央只显示装备名称、境界、价格、加成和当前状态，不展示人物预览。

商店操作后会立即刷新灵石、拥有和装备状态。洞府人物外观当前在下次人物资源加载时更新；历练战斗进入时会直接读取最新装备。

## 商店 UI 资源

运行资源位于：

```text
docs/images/sdcard/immortal_pet/shop/
```

设备读取：

- `shop_background.rgb565`：480×480 RGB565 背景；
- `shop_primary_button.png`：购买/装备主按钮；
- `shop_previous.png`、`shop_next.png`：左右切换按钮；
- `shop_back.png`：返回按钮；
- 其他卡片、状态和境界素材由资源生成脚本保留。

重新生成：

```powershell
py -3 .\firmware\device\scripts\immortal_pet\build_shop_assets.py
```

## 人物与武器资源

装备外观来自 `layered_idle` 分层人物，不生成身体与武器合成 PNG：

- 70–130 档套装使用独立身体和武器层；
- 140–170 档套装本身带武器，独立武器层为空；
- 枪使用金系人物系列，扇子使用火系人物系列；
- 男女人物分别选择对应的完整素材目录。

生成分层资源：

```powershell
py -3 .\firmware\device\scripts\immortal_pet\build_layered_idle_assets.py
```

最后将 `docs/images/sdcard/immortal_pet/` 复制到 TF 卡根目录。
